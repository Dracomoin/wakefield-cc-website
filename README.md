# Wakefield CC LLP Website — V2

Premium responsive static site in HTML/CSS/JS.

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install Live Server (Ritwick Dey).
4. Right-click `index.html` → Open with Live Server.
